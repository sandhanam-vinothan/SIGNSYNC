# SIGNSYNC
### AI-Powered Indian Sign Language Translator
SIGNSYNC is a full-stack AI-powered web application
designed to recognize Indian Sign Language (ISL)
and convert supported signs into text and speech.
## Project Objectives
- Real-time webcam-based ISL recognition
- Image-based sign recognition
- Recorded video translation
- Continuous sign sequence recognition
- Text and speech generation
- Emergency SMS notifications
- Interactive ISL learning platform
## Technology Stack
- Python 3.11
- FastAPI
- TensorFlow / Keras
- MediaPipe
- OpenCV
- HTML, CSS and JavaScript
- SQLite
## Development Status
Phase 1: Environment setup and GitHub integration.
AI recognition and translation accuracy will be
evaluated using suitable ISL datasets.
